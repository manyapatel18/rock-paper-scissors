# 🪨📄✂️ Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**.  
The player competes against the computer, with scores updated live after each round.

---

## 🎮 Game Overview

- The player selects **Rock**, **Paper**, or **Scissors** by clicking emoji buttons
- The computer randomly chooses its move
- The result (Win / Lose / Draw) is displayed instantly
- Scores for both player and computer are tracked

---

## ✨ Features

- Emoji-based buttons for better user experience
- Random computer choice generation
- Clear win, lose, and draw logic
- Live score updates
- Clean and simple UI
- Runs directly in the browser

---

## 🛠️ Technologies Used

- **HTML** – Game layout and structure
- **CSS** – Styling, colors, and button effects
- **JavaScript** – Game logic, events, and score tracking
